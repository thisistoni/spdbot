# Outfit

`outfit.ttf` is the unmodified variable font used by
[SPD-Studio](https://github.com/thisistoni/SPD-Studio/blob/fd7ddaba5e5853757298ccdf6d7ba2dbc21b2e60/public/fonts/outfit.ttf)
(weights 100–900). It is bundled locally so the SPD theme works offline and
does not send font requests to third parties.
